# 公众号排版手册

本手册定义「公众号排版工坊」的统一排版格式。你（或 AI）只需用普通 Markdown 写正文，
在需要特殊版式的地方插入 `:::模块` 标记，再用 `render.py`（或单文件网页版）渲染成可直接
粘贴进公众号后台的 HTML。文中的栏目名、作者名均为示例占位，可替换成你自己的。

---

## 一、核心思路

- 正文：普通文字，一段就是一段，**不要**自己加空格凑格式、不要用全角空格缩进。
- 特殊版式（刊头、章节标题、截图卡片、引用、视频位、结尾、名片）：用 `:::模块名` 标记。
- 强调：用 `**文字**` 加粗；链接用 `[文字](网址)`。
- 渲染后所有配色、字号、间距、卡片样式自动统一，无需手动调。

标记有两种形态：

1. **单行型**：`:::模块名 参数`，占一行，例如章节标题、截图。
2. **包裹型**：

   ```
   :::模块名 参数
   （这里是内容，可多段）
   :::
   ```

---

## 二、模块语法总览

| 模块 | 形态 | 作用 |
|---|---|---|
| `issue` | 包裹 | 文章顶部的刊头大卡片（栏目名 / 日期 / 封面 / 编者按） |
| `part` | 单行 | 章节大标题（编号 + 中文标题 + 英文副标题） |
| `sub` | 单行 | 章节内部的小标题（蓝色竖条） |
| `shot` | 单行 | 截图 / 图片卡片，可带图注 |
| `quote` | 包裹 | 引用块（左蓝竖条 + 浅蓝底），可带标签 |
| `video` | 单行 | 视频卡片（上方16:9视频位插素材库视频，下方保留标题/说明） |
| `card` | 包裹 | 延伸阅读 / 推荐卡片（封面图 + 标题 + 摘要 + 按钮；主题可降级为横向无图无按钮） |
| `end` | 单行 | 结尾的 END 分隔线 |
| `author` | 包裹 | 作者名片（头像 / 名字 / 身份 / 简介） |

> 主题还可以有自己的扩展模块（如翠绿科技的 `note/tip/warning/step/code/table` 等），
> 以该主题的 `examples/demo-<主题>.md` 为准；主题没实现的模块会自动降级，不会报错留白。

## 三、各模块详解

### 1. issue 刊头（每篇文章开头放一次）

```
:::issue 栏目名 · AI 实践手记|2026.10
封面图片地址
EDITOR'S NOTE · 本期实测

这里是编者按导语第一段。

这里是编者按导语第二段（可选）。
:::
```

说明：
- 第一行：`:::issue` 后用 `|` 分隔「栏目名」和「日期」。
- 内容第一行：**封面图地址**（图片 URL；本地图片见第六节说明）。
- 第二行：编者按小标签文字（如 `EDITOR'S NOTE · 本期实测`）。
- 空一行后：编者按导语，可一段或多段。

### 2. part 章节大标题

```
:::part 01|这单最麻烦的，反而不是写方案|DATA COLLECTION
```

- 三个参数用 `|` 分隔：**编号 | 中文标题 | 英文副标题**。
- 编号一般用 `01`、`02`……；英文副标题可简短概括本章（如 `DATA COLLECTION`）。

### 3. sub 小标题（章节内分点）

```
:::sub 先读图，再动手
```

用于一个章节内部需要再分小点、又够不上独立章节时。

### 4. shot 图片 / 截图卡片

```
:::shot 图片地址|这是图片下方的图注（可选）
```

- 第一个参数：图片地址。
- `|` 后的图注**可省略**；不写就没有图注：

  ```
  :::shot 图片地址
  ```

### 5. quote 引用块

```
:::quote 我的指令
帮我用 html 1:1 制作该户型的 3D 可互动页面。
:::
```

- `:::quote` 后的标签（如「我的指令」）**可省略**。
- 中间可放一段或多段文字。

### 6. video 视频占位块

```
:::video 最终效果：能走进去的 3D 样板间|拖着视角在房间里转，提前看见家
```

- 两个参数用 `|` 分隔：**标题（用哪个视频）| 说明**，说明可省略。
- **重要：视频本身不是普通样式。** 微信里的视频必须先上传到公众号「素材库」，再从素材库引用，
  它是一个视频播放框，无法用网页样式生成；**但视频可以放进一个卡片框里**。
- 渲染结果是一张**视频卡片**：
  - 上方是一个 16:9 的深色**视频位**（写着「在此插入视频」+ 操作提示）；
  - 下方是你的**标题和说明文字**。
- 发布操作：把**光标放进上方视频位**，点后台工具栏「视频」，从素材库上传/选择对应视频——
  视频会留在卡片框内，**下方标题/说明文字保持不变**；视频位里的提示文字被视频替换。
- 视频卡片各主题统一（由内核生成）。

### 7. card 延伸阅读 / 推荐卡片

```
:::card
![封面](https://example.com/related.png)
### 延伸阅读的标题
这里是一两句摘要。
[阅读全文](https://example.com/related)
:::
```

- 包裹型，无位置参数，内容按元素识别：第一个图片为**封面**（可省略），
  `### 标题`（或第一段文字）为**标题**，其余段落为**摘要**，第一个链接为**按钮**。
- 各主题按需取用：默认主题是纵向封面卡（图 + 标题 + 摘要 + 按钮）；
  `暖橙横向` 等主题呈现为横向、无图无按钮的精简卡。字段给全最稳妥，换主题自动适配。
- 可在一篇里多次使用。

### 8. end 结尾线

```
:::end
```

正文结束、作者名片之前放一条。

### 9. author 作者名片（每篇结尾放一次）

```
:::author 作者名|AI PRACTITIONER
我是作者名，分享实测的 AI 工具、AI 应用和工作流，主打手把手教学。
:::
```

- 第一行：`:::author` 后用 `|` 分隔「名字」和「英文身份」。
- 内容：作者简介，一到两句。
- 头像自动取名字的第一个字，无需单独提供。

## 四、基础元素

### 普通段落

直接写文字，段落之间空一行：

```
这是第一段。

这是第二段。
```

### 列表

用 `-` 或 `*` 开头，每行一条（渲染成带「•」的正文行）：

```
- 国庆酒店行情要查，房价怎么定要有依据。
- 自媒体怎么投、预算怎么拆要算清楚。
- 还得整理成 Word 方案和 Excel 预算表。
```

### 加粗

```
这行里有**需要重点强调的内容**，会显示为深色加粗。
```

### 超链接

```
感兴趣可以访问[作者主页](https://example.com)。
```

显示为蓝色下划线、可点击。

## 五、整篇文章模板（直接复制套用）

```
:::issue 栏目名 · AI 实践手记|2026.10
封面图片地址
EDITOR'S NOTE · 本期实测

用一两句话概括这篇文章要讲什么。
:::

这里是正文开头第一段。

这里是第二段。

- 这是第一个要点
- 这是第二个要点

:::part 01|第一个章节的标题|CHAPTER ONE

章节正文。

:::sub 章节内的小标题

小标题下的内容。

:::shot 图片地址|这是图注

图片后的正文。

:::quote 我的指令
引用的内容。
:::

:::video 视频标题|视频说明

:::card
![封面](https://example.com/related.png)
### 延伸阅读标题
一两句摘要。
[阅读全文](https://example.com/related)
:::

:::part 02|第二个章节的标题|CHAPTER TWO

第二章正文。

:::end

:::author 作者名|AI PRACTITIONER
我是作者名，分享实测的 AI 工具、AI 应用和工作流，主打手把手教学。
:::
```

## 六、关于图片地址

- 公众号正文里的图片最终必须是「公众号后台里的图片」。推荐流程：
  1. 先把图片在公众号后台上传（或先随便建一篇图文，把图片插入进去）；
  2. 在后台编辑器里右键图片 →「复制图片地址」，得到 `mmbiz.qpic.cn` 开头的链接；
  3. 把该链接填到 `issue` / `shot` 的图片位置。
- 也可以先填任意图床的 `https://` 链接做预览；粘贴进后台后，微信会自动把图片转存，
  但个别外链可能不显示，正式发布前请在后台逐一确认。
- 不支持直接填本地路径（如 `D:\图片\1.png`），必须是 `https://` 开头的网址。

## 七、怎么让 AI 按本格式排版已有文章

你先写好文章，把下面这段提示词连同**你的文章全文**一起发给 AI（AI 只排版，不代写）：

> 我已经写好了一篇文章，请帮我排版，输出可直接排版的 Markdown。要求：
> 1. **保留我原文的全部内容和顺序，不要替我写、扩写、缩写、改写或删句子**，只做排版；
> 2. 文章以 `:::issue 栏目名|年月` 开头，内部依次为：封面图地址占位（没有就写「封面图片地址」）、
>    小标签（如 `EDITOR'S NOTE · 本期实测`，可省略）、空行、编者按导语（可省略），以 `:::` 结束；
> 3. 每个大章节用 `:::part 编号|中文标题|英文副标题`（英文副标题可省略）；章节内分点用 `:::sub 小标题`；
> 4. 图片用 `:::shot 图片地址|图注`（图注可省略）；引用/指令用 `:::quote 标签` 包裹；
> 5. 视频位置用 `:::video 标题（用哪个视频）|说明`，渲染成视频卡片：上方 16:9 视频位
>    （后台插入素材库视频）、下方保留标题/说明；不要试图用网页样式生成视频本身；
> 6. 延伸阅读/推荐用 `:::card` 包裹：里面放可选的 `![封面](https://图片)`、`### 标题`、
>    摘要段落、`[按钮文字](链接)`；没有链接或图可以省略；
> 7. 正文正常分段，要点用 `-` 列表，原有重点用 `**加粗**`，链接用 `[文字](网址)`；
> 8. 结尾先写 `:::end`，再用 `:::author 作者名|英文身份` 加作者名片并以 `:::` 结束；
> 9. 如果我没有告诉你公众号/栏目名，刊头一律写占位「【请改成你的公众号名称】」，不要编造名字，
>    并在最后提醒我替换；
> 10. 除了排版后的 Markdown，只在最后列出需要我手动替换的占位，不要输出其它解释。

拿到 AI 排版后的 Markdown，保存为 `文章名.md`，按 README 的步骤渲染即可。
