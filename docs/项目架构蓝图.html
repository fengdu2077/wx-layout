公众号排版工坊wx-layout

目标：免费、离线、可复用的公众号模块化排版系统 —— 让 AI 每次按模块自动排版，并能低成本复刻任意公众号主题、以「内核 + 多主题」支撑未来做成服务分发给别人；替代付费 md2wechat。

一、两条核心能力线

线 A · 写作排版（日常）

把「Markdown + 模块标记」变成可直接粘贴的微信正文。

素材/想法 → 选主题写定制 md → 渲染微信 HTML → 一键复制 → 后台 Ctrl+V

线 B · 主题生产（偶尔）

把任意公众号文章归纳成一套可插拔主题，增量进主题库。

目标文章 → skill 提取归纳 → themes\新主题.py → 回填验证 → 入库

二、两个 AI Skill（随仓库 skills/ 提供）

wx-theme-extractor

Skill 1 · 主题提取器（线 B · 偶尔）

  • 输入：目标文章保存页（.mhtml/.html，取 #js_content）+ 主题名
  • 脚本抽 DOM 与样式；AI 做语义归纳、槽位识别、令牌提炼，样式只来自真实页面
  • 生成 themes\新主题.py 与 web/themes JS 双端，diff 保真 + parity 校验后入库
wx-layout

Skill 2 · 排版器（线 A · 高频入口）

  • 输入：用户已写好的成稿（文件或全文）+ 指定主题（或默认）；只排版、不代写
  • 读目标主题的「模块契约」，保留原文、只加 :::模块 标记
  • 调 render.py 渲染、打开预览、一键复制

边界：两个 skill 都不自己渲染，渲染由确定性程序 render.py / wx_core 完成。AI 负责看懂，程序负责精确。 两个 skill 位于 skills/（含 SKILL.md、参考文档与脚本），可安装到 Agent 或直接让任意 AI 照做。 （可选 Skill 3「后台发布器」：自动登录、传草稿、插图、群发，当前手动粘贴，暂不做。）

四、核心机制：role + 字段契约 + fallback

作者写「语义 + 全量字段」，主题决定「用哪些字段、怎么排」；不引用的字段自然不渲染，字段缺失走降级。

① 作者写一次 :::card

:::card
![封面](cover.jpg)
标题文字
这是摘要内容……
[阅读更多](https://…)
:::

② 解析为字段对象（IR）

role: card
fields:
  image  : cover.jpg
  title  : 标题文字
  summary: 这是摘要…
  link   : https://…
  action : 阅读更多
主题 A · 纵向 / 全字段
封面图
阅读更多
主题 B · 横向 / 仅标题摘要
不渲染图片 / 按钮

三个契约条件：⓵ 模块解析成 role + 字段字典（非位置文本）；⓶ 主题模板按字段取用、自定布局；⓷ 字段可选，缺失用占位/省略/默认值降级，不报错留白。 常用 role 定标准字段契约以保证跨主题可迁移；极端版式可用「主题特有 role」，但换主题时走 fallback。

五、三条设计原则

AI 看懂，代码执行

归纳 / 写稿交给 AI；解析 / 渲染 / 复制 / 提取 / diff 交给确定性脚本。

内核共享，主题隔离

稳定通用的 wx_core 只一份；易变、差异大的模板每套独立。

只做增量，不改存量

加主题 = 新增一个文件，老主题零改动，杜绝连锁回归。

七、关键技术事实（踩坑沉淀）

微信格式

  • 只保留内联样式；class / 外部 CSS / <style> 被过滤。
  • 文字包 <span leaf="">；加粗 <span textstyle="">；图片有 span 包裹。
  • 列表用文本 • ，不用 ul/li。

复制

  • 必须 ClipboardItem 直写原始 HTML。
  • 手动 Ctrl+A 会带入数百处计算样式污染、抹掉 flex。

抓取与素材

  • mp.weixin curl 报「环境异常」；保存网页或 skill 驱动内置浏览器。
  • 视频 / 小程序 / SVG 静态提取不到 → 占位 + 后台手动替换。

蓝白主题令牌（真实值）

  • 色：#2563eb / #3b82f6 / #dbeafe / #111827 / #374151 / #9ca3af
  • IBM Plex 字体栈；正文 15px / 1.95 / 两端对齐。
  • 原文官方校验仅 2 处背景渐变，无行高 / 对齐问题。
