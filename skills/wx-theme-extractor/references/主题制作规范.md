# 主题制作规范（Python + JS 双端）

> wx-theme-extractor 产出主题时的接口手册。**内核只有一份（`wx_core.py` / `web/core.js`），
> 主题是纯增量文件**：新增主题不改内核、不改老主题。先读一个最接近的现有主题当骨架
> （杂志→蓝白杂志、手记→暖棕手记、技术→翠绿科技、横向轻量→暖橙横向）。

## 1. Python 主题：`themes/<中文label>.py`

### 1.1 元数据

```python
THEME = {
    "name": "green-tech",        # 英文代号，短横线小写；对应 web/themes/green-tech.js
    "label": "翠绿科技",          # 中文显示名（render.py / 主题下拉展示）
    "version": "1.0",
    "containers": ["step"],       # 本主题额外的「包裹型」role（单独一行 ::: 闭合）
    "tokens": {                   # 设计令牌：所有颜色/字号/字体只从这里取
        "BLUE": "#059669",        # 链接色/主色（键名 BLUE 是内核约定，值可换）
        "BOLD_INK": "#059669",    # **加粗** 颜色
        "INK": "#111827", "TEXT": "#374151", "MUTED": "#9ca3af",
        "PAGE_BG": "#ffffff",
        "FONT": "-apple-system,...,'Microsoft YaHei',sans-serif",
        # 其余令牌按需自定义（圆角色、背景色、MONO 等），render 函数里用 c.t 取
    },
}
```

### 1.2 渲染函数

每个 role 一个函数，签名固定 `render_<role>(b, c)`：

- `b`（IRBlock，解析产物）：
  - `b.get(i, default="")`：指令行第 i 个 `|` 位置参数（i 从 0 起）。
  - `b.pos`：全部位置参数列表；`b.kw`：`key=value` 参数（如 `:::shot x|图注 round=1`）。
  - `b.fields`：body 解析出的命名字段——`image/images`、`heading/headings`、
    `paras`、`lists`、`link/links`、`text`（普通段落拼接文本）。
  - `b.blocks`：body 的通用元素数组，元素 `type ∈ para/heading/image/list/link`。
  - `b.bullet`：正文是否为 `-` 列表项（正文行渲染时前面加「• 」）。
- `c`（Engine）：
  - `c.leaf(text)`：正文文本转义 + 行内格式（`**加粗**`、`[文字](url)`），
    并包成 `<span leaf="">…</span>`——**所有可见文字必须经它处理**。
  - `c.inline(text)`：同上但不包 leaf（嵌在已有 leaf 里时不要用）。
  - `c.esc_attr(text)`：HTML 属性值转义（**图片 src / href 必须用它**）。
  - `c.t`：令牌字典（`THEME["tokens"]`）。
  - `c.video_placeholder(b)`：内核统一的视频卡片（新主题一般不用自己写视频）。

函数返回内联样式 HTML 字符串，例如：

```python
def render_sub(b, c):
    return (
        '<section style="margin:24px 0 0;border-left:3px solid %s;padding-left:10px;">'
        '<p style="margin:0;font-size:15px;font-weight:800;color:%s;">%s</p>'
        '</section>'
    ) % (c.t["BLUE"], c.t["INK"], c.leaf(b.get(0)))
```

### 1.3 注册与降级

```python
ROLES = {
    "para": render_para,
    "issue": render_issue,
    # ... 本主题实现的每个 role
}

def fallback(b, c):        # 可选；未实现的 role 由它渲染，不写则用内核默认降级
    ...
```

- 内核已认识的包裹型 role（默认容器）：`issue quote author card gallery callout faq
  timeline compare steps highlights profile toc stats keyvalue note tip warning code
  table cta audio`；单行 role：`part sub shot video end divider image`。
- 本主题新造的包裹型 role 要加进 `THEME["containers"]`（如翠绿科技的 `step`）。
- 不实现的 role 会自动 fallback（视频走内核视频卡片、正文走默认段落、未知块走灰底
  提示框），**不报错、不留白**；写稿端给全字段即可跨主题复用。

### 1.4 主题本地行内标记

需要 `==高亮==` 之类的主题专属行内语法时，在主题内实现自己的 inline 函数
（参考翠绿科技 `green_inline`、暖棕手记）：先 `html.escape`，再用正则替换为带样式
`<span>`，render 函数里用它替代 `c.leaf`；标记符号要写进主题头部注释和 demo。

### 1.5 微信适配硬约束

- 只输出**内联样式**，不用 class / 外链 CSS / `<style>`（粘贴后会被微信剥掉）。
- 文字节点必须包 `<span leaf="">`，加粗用 `<span textstyle="" style="...">`。
- 图片：`<span leaf=""><img src="https://..." style="max-width:100%;..."/></span>`，
  src 用 `c.esc_attr`；**不支持本地路径**。
- 视频不自己实现，复用 `c.video_placeholder(b)`。
- Python 字符串用 `%` 格式化时，CSS 的百分号要写 `%%`（如 `border-radius:50%%`、
  `max-width:100%%`）；JS 端**没有这个转义**。
- 文字底色渐变在后台会提示「文字背景尽量不要使用渐变」，这是微信编辑器的已知提示，
  装饰性渐变（无文字）通常无碍；复刻时以原文为准，不要新增原文没有的渐变。

## 2. JS 主题：`web/themes/<英文name>.js`

与 Python 版逐 role 忠实移植（纯网页版/单文件版用）：

```javascript
(function (global) {
  "use strict";
  var THEME = { name: "green-tech", label: "翠绿科技", version: "1.0",
                containers: ["step"], tokens: { /* 与 Python 完全一致 */ } };

  function renderPara(b, c) { /* c.leaf / c.escAttr / c.t / c.videoPlaceholder */ }
  // ... 每个 render_<role> 对应一个 render<Role>（驼峰名）

  var ROLES = { para: renderPara, issue: renderIssue /*, ...键名与 Python 一致 */ };
  // 有自定义降级时：function fallback(b, c) { ... }，并在注册对象里加 fallback: fallback

  global.WX.registerTheme({ THEME: THEME, ROLES: ROLES });
})(window);
```

- 移植后必须在 `web/index.html` 加 `<script src="themes/<name>.js"></script>`。
- JS 无 `%%` 转义；无 Python `%` 格式化，直接字符串拼接；布尔/空值用 `||`、`?:`。
- 两端渲染结果必须**字节级一致**（由 `tools/web_parity` 把关）。

## 3. 新增主题要改动/登记的文件清单

| 文件 | 改动 |
|---|---|
| `themes/<label>.py` | 新增 Python 主题 |
| `web/themes/<name>.js` | 新增 JS 主题 |
| `web/index.html` | 加一行 `<script src="themes/<name>.js"></script>` |
| `examples/demo-<label>.md` / `.html` | 由 `scaffold_demo.py` 生成骨架后润色、渲染 |
| `tools/web_parity.py` | `SAMPLES` 加 demo 条目；`THEME_FILE` 加 `"<name>": "<label>"` |
| `tools/web_parity.js` | 顶部 `load("web/themes/<name>.js")` |
| `tools/build_web_samples.py` | `SAMPLES` 加主题 demo 条目，再重跑生成 `web/samples.js` |
| `README.md` / `docs/AI调用指南.md` | 主题列表与主题对照表登记 |
| `dist/公众号排版工坊.html` | 跑 `tools/build_web_single.py` 重新打包 |

```bash
python tools/extract_dom.py "<原文.mhtml>" --outdir tools/analysis
python tools/diff_render.py --page "<原文.mhtml>" --md "<复刻.md>" --theme <label> --out tools/analysis/diff.html
python tools/diff_style.py "<原文.mhtml>" "<复刻渲染>.html"       # 退出码 0
python tools/scaffold_demo.py <label> --render
node tools/web_parity.js && python tools/web_parity.py           # 双端字节级一致
python tools/build_web_samples.py
python tools/build_web_single.py
```
